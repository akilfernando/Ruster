## Authorization and intended outcome

The user authorized autonomous work through M9, short-term adjustments serving the creator outcome, and an evaluation after each milestone. The engine should let creators build their own games, simulations and visual applications through familiar tools, approachable scripting or Rust, recoverable iteration and standalone distribution. Rust/Vulkan, openness, optional native MCP/manual parity, documentation continuity and everyday editor quality are requirements. Lean implementation and measured optimization are explicit priorities.

The user mainly knows Unity. Their first walkthrough was good overall but identified aliasing, missing Enter rename submission and expected perspective/ISO views. Keyboard fluency is explicitly reinforced. Those fixes are implemented; full creator acceptance remains separate. No Unreal tester is available, so that familiarity evidence is unverified, not waived. See [direction](DIRECTION.md), [roadmap](ROADMAP.md), [experience](EDITOR-EXPERIENCE.md) and [performance policy](PERFORMANCE.md). Milestone counts are not a completion percentage.

## Implemented state

- Generic authoring: blank startup, immutable IDs/display names, create/rename/duplicate/delete, multi-selection/internal clipboard, one-revision grouped commands, transient move/rotate/scale, snapping/local axes/pivots and mixed precision. Gesture cancellation protects authored state. Exact TRS rules restrict shear-producing world nonuniform group scale. Physical native handles remain unverified.
- Workspace/view: bounded persisted layout/visibility/scale/shortcuts/recent paths/camera; Enter/Escape ownership and guarded normal close; perspective/orthographic, axis/isometric presets, frame/pan/fly controls. New default shortcut conflicts preserve existing remaps and expose Unbound actions. Search/context menus/internal mesh drops validate exact target/catalog/session/revision and preserve pending drafts.
- Content/rendering:256objects/64assets, one opaque RGB viewport, procedural cubes or bounded triangle OBJ. Explicit OBJ/WGSL refresh and last-good recovery; binary derived cache2 with validated v1 fallback and stable Arc snapshots. Initial4× MSAA resolves into existing compositing, bounded by256MiB retained target payload. Catalog mutations persist separately from scene Undo. Extreme imported extents can exceed current camera/persistence bounds.
- Scene5: language-neutral embedded sources/bindings/typed properties, unfinished/unknown-language saves, shared flat history, strict v1–v4 migrations and original-byte duplicate-key rejection. Compact counting/writing preserves reachable Undo/Redo within1MiB; successful new edits may evict oldest Undo entries while retaining newest. Visible pressure feedback; failure/stale/no-op/Undo/Open never evict. Atomic create_behavior creates source+attachment together. Geometry-only loading rejects live or historical authoring instead of stripping it.
- Recovery: complete snapshots restore as unsaved copies without source-overwrite authority; original asset origin stays separate. Per-machine bounded journals retain invalid numeric/offset/name drafts. One serial worker handles capture/encoding/hashing/fsync, coalescing edits and acknowledging retirement/adoption. Close keeps painting and surfaces cleanup conflicts. Tests use detached/disposable state. Trusted local/cooperating-writer guards are not hostile-filesystem or universal power-loss isolation.
- Scripting foundation: separate provisional Lua5.4.9 backend, immutable tick-start inputs, fresh environments/modules, scoped resolver callbacks, atomic ticks, budgets/cancellation and contextual diagnostics. Headless check/run emits JSON and never changes authored bytes. No mandatory interpreter in ruster-app. Generic editor behavior execution/tooling is **not implemented yet**; [next-stage plan](BEHAVIOR-AUTHORING.md) owns the concrete work. Rhai/Motion Lab project1 remains compatible and separate; its legacy Save still requires runnable code.
- M7 kit/Yard: application-owned behavior/UI/lifecycle/input, bounded scheduling, read-only resources and independent Linux development export. Historical binary requiresGLIBC2.44; no release/support promise. [Distribution](DISTRIBUTION.md), [M7 evidence](evidence/M7.md).
