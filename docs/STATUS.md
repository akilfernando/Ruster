## Authorization and end state

The user authorized autonomous development through M9, adjustments serving the creator outcome, and an evaluation after each milestone. The engine should help creators build their own games, simulations and visual applications through familiar tools, approachable scripting or Rust, recoverable iteration and standalone distribution. Rust/Vulkan, openness, optional native MCP/manual parity, documentation continuity and everyday editor quality are requirements. Lean, efficient code is an explicit priority: measure before retaining optimizations. ## Run

```sh
cargo run --locked -p ruster-editor -- --scene examples/content/scene.json
cargo run --locked -p ruster-scene -- new /tmp/my-scene.json my-scene
cargo run --locked -p ruster-editor -- --scene /tmp/my-scene.json
cargo run --locked -p ruster-motion-lab -- --headless --ticks 10 --speed 2
cargo run --locked -p ruster-yard -- --resources examples/yard-app/resources
python3 scripts/new_app.py /tmp/my-ruster-app
```

Choose fresh destinations. Guides: [scene](../crates/ruster-scene/README.md), [editor](../crates/ruster-editor/README.md), [Motion Lab](../examples/motion-lab/README.md), [Yard](../examples/yard-app/README.md).
