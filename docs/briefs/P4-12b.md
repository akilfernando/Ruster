# P4-12b · Script properties declared in the script, references, tags, prefab spawn

Lane Play · Size M · Depends on: P4-12a

**Outcome.** A script lists its own properties and the Inspector shows them
with defaults. A property can point at an object, an asset or a prefab, set
by dragging. Objects have tags. A script spawns a prefab asset.

**Why.** In Unity a public field appears in the Inspector by itself, and
dragging an object or prefab onto it is the everyday way to wire a scene.
`Instantiate(prefab)` is how games create things.

**Facts.** Checked 2026-11-27.

- A creator adds each script property by typing its name in the Inspector.
  Nothing connects that name to the script.
- `PropertyValue` (`rot-scene/src/authoring.rs`, about line 173) has Number,
  Bool, Text, Vec3, ObjectRef, AssetRef, SoundRef and SensorRef. The
  Inspector edits only Number, Bool and Vec3, plus sound cues and sensors
  (`rot-editor/src/scene_editor/component_property.rs`). The Text, ObjectRef
  and AssetRef editors exist only in test code.
- `host.spawn(template, pose, parent)` clones an authored object that is
  already in the scene. It cannot take a prefab asset.
- `ObjectNode` has no tags. `host.find` matches id or name.
- Dragging an object from the Hierarchy onto a field is not implemented.

**Do.**

1. A module may return a `properties` table:
   `properties = { speed = 5.0, lives = 3, label = "Player",
   offset = {0, 1, 0}, target = "object", bullet = "prefab",
   hit = "sound" }`. A number, boolean, string or three-number table
   declares that type with that default. The strings `"object"`, `"asset"`,
   `"prefab"` and `"sound"` declare an empty reference.
2. The Inspector lists the declared properties in order, with their
   defaults, as soon as the script is attached and after each reload.
   A value the creator sets overrides the default and is saved. A saved
   value whose property was removed stays in the file and shows under a
   collapsed "Unused" row with a Remove button.
3. Editors: Text is a text field. Object reference and asset reference are
   [reference fields](../UX-STANDARDS.md#5-components): a picker, drag from
   the Hierarchy or Assets, click to reveal. Each commits at once as one
   Undo step, with no Apply button, whether or not `U-04` has landed.
4. In Lua, `props.target` is an object handle and `props.bullet` is a value
   `host.spawn` accepts.
5. `host.spawn(prefab, pose, parent)` creates an instance of a prefab asset
   with all its children and components. Build includes every prefab that a
   property references.
6. Tags: an optional `tags` list on `ObjectNode`, edited in the Inspector
   header. `obj:has_tag(name)`, `host.find_with_tag(name)`,
   `host.find_all_with_tag(name)`.
7. Add all of it to the component catalog, the MCP schema and
   `docs/LUA-API.md`. The existing `set_script_number`, `set_script_bool`
   and `set_script_vec3` MCP operations gain `set_script_text` and
   `set_script_reference`.

**Sample.** `player.lua` declares speed and jump height. The coin is a prefab
that `game.lua` spawns through a `"prefab"` property. Coins and hazards are
found by tag.

**Done when.**

- In-process tests: attaching a script shows its declared properties;
  dragging an object onto a reference field sets it as one Undo step;
  removing a declaration moves the saved value to Unused.
- Runtime tests: defaults reach `props`; a prefab spawns with its children;
  `find_all_with_tag` returns every tagged object.
- Save, reopen and Build keep references, including after the target is
  renamed or the asset is moved.
- A real AI client sets an object reference through MCP.

**Not now.** Arrays and nested tables as properties. Enums and ranges.
