# P4-07b · Music, streaming and mixer buses

Lane Play · Size M · Depends on: P4-07a

**Outcome.** A creator drops in an OGG or MP3 music track, it streams from
disk instead of loading whole, and Music, SFX and UI each have a volume a
script can change.

**Why.** Unity has compressed audio with a Streaming load type and an Audio
Mixer with groups. A game needs separate music and effects volume sliders.

**Facts.** Checked 2026-11-27.

- Import accepts WAV only, PCM16, through `hound` in
  `rot-assets/src/audio.rs`.
- Every clip is decoded fully into memory.
- All sound goes to kira's main track. There are no buses.
- kira can decode and stream OGG, MP3 and FLAC through its `symphonia`
  feature. New crates need `python3 scripts/dependency_notices.py`.

**Do.**

1. Import `.ogg`, `.mp3` and `.flac` as sound assets beside `.wav`. Read
   duration, channels and sample rate at import for the Inspector.
2. Add a Load Type import setting on a sound asset, stored in its
   `.rotmeta`: `Decompress On Load` (default for clips under 10 seconds) and
   `Streaming` (default for longer clips). Streaming plays from the file
   with kira's streaming sound.
3. Build copies the source audio file for streamed clips and keeps the
   current packaging for the rest.
4. Buses: Master always exists. Music, SFX and UI exist by default. Project
   Settings, Audio lists the buses, each with a volume slider, and lets a
   creator add, rename and remove buses other than Master.
5. Audio Source gains a `bus` field (default SFX). Sound cue one-shots go to
   SFX.
6. Lua: `host.audio.set_bus_volume(name, 0..1)`,
   `host.audio.bus_volume(name)`, `host.audio.set_paused(bool)`. Bus volume
   changes fade over 50 ms.
7. Pausing the game pauses every bus except UI.
8. Add to the MCP schema and `docs/LUA-API.md`.

**Sample.** A looping music track on the Music bus. A key lowers music
volume. Pausing mutes everything but a UI click.

**Done when.**

- Import tests with one small file per format, each under 100 KiB and CC0.
- Memory test: starting a three-minute streamed track raises process memory
  by less than 8 MiB.
- Recording-backend tests: bus volume scales its sources and no others;
  pause leaves UI playing.
- The built sample plays its music from a moved folder.
- A person hears the music loop without a gap or click at the loop point.

**Not now.** Effects on buses (reverb, low-pass), ducking, snapshots, a mixer
panel with meters, audio compression at Build.
