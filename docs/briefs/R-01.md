# R-01 · GPU probes: one command, all green

Lane Repair · Size S · Depends on: nothing

**Outcome.** Rendering is protected by checks that run with one command and
actually fail when rendering breaks.

**Facts.** Checked 2026-11-27 at `c67b7d3` on the RTX 4060.

- The gate and CI never run `#[ignore]` tests. Eight of them are GPU probes
  that need only a Vulkan adapter. `python3 scripts/check.py --gpu` runs them
  in a debug build.
- Three fail today:
  - `debug_views_probe::shading_debug_views_gpu_probe` panics with
    `attempt to add with overflow` at `rot-render/src/debug_views_probe.rs:378`
    (`d_near[0] > d_far[0] + 60` on `u8`).
  - `ibl_gpu::tests::atmospheric_fog_gpu_probe` panics the same way at
    `rot-render/src/ibl_gpu.rs:1115` (`horizon_clear[0] + 80`).
  - `tests::shader_rejection_preserves_renderable_pipeline` fails in debug
    and release at `rot-render/src/material_probe.rs:86`:
    `gray/color-space mismatch: [0, 0, 0, 0]`. The legacy pipeline draws
    nothing.
- In a release build the two additions wrap, so those assertions pass
  without testing anything. That is how they were reported green.

**Do.**

1. In every probe, compare pixels with `i32` values (`i32::from(a[0])`).
   Search: `grep -nE "\] *[<>]=? *[a-z_]+\[[0-9]\] *[+-] *[0-9]" crates/rot-render/src`.
   On 2026-11-27 it finds 23 lines in six files. Any of them can pass by
   wraparound, not only the two that panic today.
2. Rerun. If a widened assertion now fails, decide which side is wrong by
   reading the shader: the Depth view in `composite.wgsl` or `surface.wgsl`,
   and the sky fog blend in `sky.wgsl`. Fix the shader when the picture is
   wrong. Fix the expectation, with a one-line comment, when the picture is
   right. Look at the rendered image before deciding.
3. Find the commit that broke the pipeline probe. First find a commit where
   it passes: try `62fe99c` (the Phase 2 exit), then older ones such as
   `cf94261`. Then `git bisect start c67b7d3 <good>` and `git bisect run
   cargo test -p rot-render --locked -- --ignored --exact
   tests::shader_rejection_preserves_renderable_pipeline`. Fix the pipeline
   or the probe's setup. If the custom shader path it protects is no longer
   reachable from the editor, say so in the commit and keep the probe for
   the path that is.
4. Run the eight probes in release too:
   `cargo test --release -p rot-render --locked -- --ignored --test-threads=1 gpu_probe phase3b_interior_exit_gate_probe shader_rejection_preserves_renderable_pipeline`.

**Done when.**

- `python3 scripts/check.py --gpu` passes.
- The release command in step 4 passes.
- No probe assertion does arithmetic on `u8` pixel values.
- The commit message names the first bad commit for the pipeline probe, what
  was wrong, and whether each of the two overflow checks hid a real defect.

**Not now.** New probes. Running probes in hosted CI (there is no GPU).
