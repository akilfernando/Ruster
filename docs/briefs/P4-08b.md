# P4-08b · Gamepad and rebinding

Lane Play · Size M · Depends on: P4-08a

**Outcome.** A game plays with a gamepad as well as keyboard and mouse, and a
player can change a binding from an options menu.

**Why.** Unity and Unreal both map one action to keyboard, mouse and gamepad
at once, and both let a game rebind at runtime.

**Facts.** Checked 2026-11-27.

- No gamepad code exists. `gilrs` is the usual Rust crate and works on
  Linux, Windows and macOS.
- Bindings are authored in the scene's action map and cannot change while a
  game runs.
- Adding a dependency means regenerating `docs/DEPENDENCIES.md` and
  `THIRD_PARTY_NOTICES.txt` with `python3 scripts/dependency_notices.py`.

**Do.**

1. Add `gilrs` to `rot-app`. Poll it once per frame in `rot-app/src/host.rs`
   and in editor Play, and feed the same accumulator as keys.
2. Sources: the four face buttons, both shoulders, both stick clicks, Start,
   Select and the D-pad as buttons; left stick X and Y, right stick X and Y
   and both triggers as axes. Name them by position (South, East, West,
   North), as `gilrs` does.
3. A Button action lists gamepad buttons beside keys and mouse buttons. An
   `Axis1d` action can name a gamepad axis. Apply a dead zone, default 0.15,
   set per project under Project Settings, Input. Keys and stick add and
   clamp to the range -1 to 1.
4. Use the first connected pad. `host.gamepad_connected()` returns a bool.
   Unplugging and plugging back in must not need a restart.
5. Rebinding from Lua:
   - `host.bindings(action)` returns the current sources as strings.
   - `host.capture_binding(action, slot)` binds the next key, button or
     axis the player uses and emits a `binding_changed` event. Escape
     cancels.
   - `host.reset_bindings()` restores the authored map.
   Changes last for the Play session. `P4-10c` will save them.
6. Input Actions editor: capture accepts a gamepad button or axis. Show a
   small controller icon on those rows.
7. Play Checks replay gamepad values as action values, with no device.
8. Add to the MCP input schema and `docs/LUA-API.md`.

**Sample.** Left stick moves, right stick orbits the camera, South jumps.
An options screen arrives with `P4-09a`; until then bind a key that calls
`host.capture_binding("jump", 1)`.

**Done when.**

- Tests with synthetic device events: dead zone, key plus stick clamping,
  capture, cancel, reset, reconnect.
- The Windows CI job (`cargo check --workspace`) passes with the new crate.
- A person or the user confirms with a real controller that the sample
  plays. If no controller is available, say so in the commit and add a line
  under Needs the user in [BACKLOG](../BACKLOG.md).
- The dependency inventory check passes.

**Not now.** Several local players. Rumble. Per-device button glyphs.
