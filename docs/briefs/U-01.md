# U-01 · Docked panels and saved layouts

Lane UX · Size M · Depends on: nothing

**Outcome.** Hierarchy, Inspector, Scene, Game, Assets and Console are tabs
in one dock. A creator drags them, closes and reopens them, and the layout
is still there after a restart.

**Why.** This is the [window anatomy](../UX-STANDARDS.md#3-window-anatomy).
It was built in Phase 1 and lost when the editor was replaced.

**Facts.** Checked 2026-11-27.

- Commit `e106408` (2026-11-26) deleted `rot-editor/src/panels/` and every
  use of `egui_tiles`. The crate is still vendored in
  `third_party/egui_tiles` and still listed in `rot-editor/Cargo.toml`.
- The working implementation is in git:
  `git show e106408^:crates/rot-editor/src/panels/mod.rs` (960 lines: `enum
  Pane`, `default_tree()`, a `Behavior<Pane>`). Its commits are `7950013`
  (dock), `dec5c8a` (close, reopen, saved layout, F6) and `e74bc06`
  (Default and Side by Side).
- The original briefs, with their done-when lists, are sections S-07a,
  S-07b and S-07c of
  [the 2026-11-25 archive](../archive/BACKLOG-2026-11-25.md). Read those
  three sections only.
- Today `ComponentWorkspace::show`
  (`rot-editor/src/scene_editor/component_workspace.rs`, about line 2839)
  lays out fixed egui panels and ends in a `CentralPanel` (about line 4363).
  Play runs inside that one viewport.
- These registered commands do nothing today: `ToggleHierarchy`,
  `ToggleInspector`, `LayoutDefault`, `LayoutSideBySide`, `ResetLayout`,
  `NextPanel`, `PreviousPanel`.
- The renderer draws one 3D viewport per frame. Scene and Game therefore
  share one dock as tabs, as before.

**Do.**

1. Restore `panels/mod.rs` from `e106408^` and adapt it to
   `ComponentWorkspace`. Port, do not redesign. Keep the default tree:
   Hierarchy, then Scene and Game tabs, then Inspector across the top;
   Assets and Console tabs across the bottom.
2. Move each panel body out of `show()` into a function the dock calls. Do
   not change what the panels draw in this package.
3. Close buttons on Hierarchy, Inspector, Assets and Console. Window lists
   every panel with a check mark, then Layouts with Default, Side by Side
   and Reset Layout.
4. Save the layout to `layout.json` beside `editor.json`, as S-07b
   describes. A missing or bad file loads the default with one Console
   warning.
5. Below 1,100 px of window width switch to Side by Side, as S-07c says.
6. Make the seven commands above work. F6 and Shift+F6 move focus between
   docks.

**Done when.**

- Screenshots at 1280×800, 1920×1080 and 960×1080 match the window anatomy
  and clip nothing. View them.
- In-process tests: a pointer drag moves Console into the Inspector dock;
  closing Hierarchy unchecks it in Window and checking it restores it; a
  saved tree reloads from a temporary state path; a corrupt file loads the
  default; F6 visits each dock once.
- The scroll wheel over Hierarchy does not zoom the viewport, and clicks
  near each edge of the Scene tab pick the right object.
- `python3 scripts/ui_drive.py ... tabwalk:80` reaches every panel.

**Not now.** A separate Game view with its own aspect (`U-05`). Floating OS
windows, user-named layouts, several viewports at once.
