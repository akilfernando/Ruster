# U-05 · Game view

Lane UX · Size M · Depends on: U-01

**Outcome.** The Game tab shows what the player will see, at the game's
aspect ratio, in edit mode and in Play. Pressing Play switches to it.

**Why.** Unity's Game view and Unreal's Play In Editor both separate the
editing camera from the player's camera.

**Facts.** Checked 2026-11-27.

- Play runs inside the single scene viewport with an accent border
  (`ComponentWorkspace::viewport`, `component_workspace.rs` about line 2487).
  There is no Game tab, no aspect choice and no maximize.
- The game camera is `ComponentScene::gameplay_camera`
  (`rot-scene/src/component_scene.rs`). The player's window size and mode are
  in Project Settings, Player.
- The renderer draws one 3D viewport per frame, so Scene and Game are tabs in
  one dock and only the visible one is drawn.

**Do.**

1. Add the Game tab beside Scene in the dock from `U-01`.
2. In edit mode, Game draws the scene through the game camera with the
   scene's display settings and without gizmos, grid, selection outline or
   editor icons. With no game camera it shows an empty state with one
   action: Create Camera.
3. A small overlay in the Game tab's top-left: an aspect dropdown (Free,
   16:9, 16:10, 4:3, and the size from Project Settings), a Stats toggle
   and a Maximize on Play toggle. Letterbox the image to the chosen aspect.
4. Play switches to Game and gives it the keyboard, as clicking it does
   now. Stop returns to the tab that was active before. A preference under
   Preferences, General turns the switch off.
5. With Maximize on Play, the Game tab fills the dock area while playing.
6. While playing, selecting the Scene tab shows the running game through
   the editor camera with gizmos, so a creator can look around the live
   scene. Edits there follow the existing Play Values rules.
7. The game HUD draws only in Game.

**Done when.**

- Screenshots at 1280×800 and 960×1080, viewed: Game in edit mode at 16:9
  with letterbox bars, Game while playing, Scene while playing, and the
  empty state.
- In-process tests: Play activates Game and Stop restores the previous tab;
  the aspect choice survives a restart; the preference disables switching.
- A 5,000-object scene keeps its frame time when switching tabs. Measure
  `examples/rot-yard/riverside.scene.json` in release before and after.

**Not now.** Scene and Game visible side by side, a camera preview inset and
split-screen. They need several 3D views in one frame, which is listed in
[Phase 5A](../PARITY-PLAN.md#3-phases).
