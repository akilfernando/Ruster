# P4-14 · Collision layers and the collision matrix

Lane Play · Size M · Depends on: P4-11

**Outcome.** A creator puts objects on named layers, chooses which layers
collide in a matrix, and limits a raycast to chosen layers.

**Why.** Unity has 32 layers, a Layer Collision Matrix under Project
Settings, Physics, and a layer mask on every physics query. Unreal's
collision channels do the same job.

**Facts.** Checked 2026-11-27.

- `ObjectNode` (`rot-scene/src/component_scene.rs`) has no layer.
- `rot-behavior/src/physics.rs` never sets Rapier `InteractionGroups`, so
  every collider collides with every other.
- `host.raycast`, `host.shapecast` and `host.overlap` filter only by
  `include_sensors` and `exclude`.
- Project settings are in `.rot-project.json`
  (`rot-editor/src/scene_editor/project_settings.rs`). They reach the
  runtime through the scene given to Play and through `app.json` in a build.

**Do.**

1. Project Settings gets a Physics page: 32 layer rows. Layer 0 is
   "Default" and cannot be renamed. The rest are empty until named.
2. Below the names, a triangular matrix of checkboxes, as in Unity. All
   pairs collide by default.
3. `ObjectNode` gains an optional `layer` number, 0 to 31, default 0. The
   Inspector header shows a Layer dropdown of the named layers.
4. Give every collider Rapier interaction groups from its object's layer
   and the matrix. Apply on reset and on live edit.
5. Queries: `host.raycast`, `host.shapecast`, `host.sweep` and
   `host.overlap` accept `layers = {"Ground", "Enemy"}` in their options
   table. With no `layers`, they hit everything, as now.
   `host.layer_mask(names)` returns a reusable value.
6. Contact and trigger callbacks only fire for pairs the matrix allows.
7. Character Controller movement respects the matrix for its own layer.
8. Lua object handle: `layer` and `set_layer(name)`.
9. Deleting a layer name that objects still use shows how many use it and
   asks before continuing. Those objects fall back to Default.
10. Add to the component catalog, the MCP schema and `docs/LUA-API.md`. An
    AI app can read and set layers and read the matrix.

**Sample.** Layers Player, Ground, Enemy and Pickup. Pickups collide only
with Player. The camera's wall check uses `layers = {"Ground"}`.

**Done when.**

- Runtime tests: two bodies on layers that do not collide pass through each
  other; a raycast with `layers` skips other layers; a trigger between
  excluded layers does not fire; changing the matrix during Play applies.
- Save, reopen and Build keep layers and the matrix. An old project with no
  physics settings behaves as before.
- The physics benchmark is within 5% of its previous numbers.
- Screenshots of the Physics page at 1280×800, viewed. The matrix is
  reachable by Tab and Space.

**Not now.** Rendering layers and camera culling masks. Per-collider layer
overrides.
