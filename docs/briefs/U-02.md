# U-02 · Every command works

Lane UX · Size M · Depends on: U-01 for the layout commands only

**Outcome.** Every command in the menus, the command palette and the
Shortcuts editor does something. Copy, Paste and Select All work on objects.

**Facts.** Checked 2026-11-27.

- `Action::ALL` in `rot-editor/src/workspace.rs` registers 87 commands.
  `ComponentWorkspace::command()` in
  `scene_editor/component_workspace.rs` handles 53, three more are handled
  elsewhere, and the match ends in `_ => return` (about line 2291).
- These 31 are referenced nowhere outside the registry. They appear in the
  Shortcuts editor and do nothing: `Copy`, `Paste`, `SelectAll`, `Quit`,
  `Projection`, `Front`, `Back`, `Left`, `Right`, `Top`, `Bottom`,
  `FreeView`, `FocusRuntime`, `GameControls`, `NextPanel`, `PreviousPanel`,
  `ToggleHierarchy`, `ToggleInspector`, `LayoutDefault`, `LayoutSideBySide`,
  `ResetLayout`, `NewProject`, `OpenProject`, `GameCamera`, `GameUi`,
  `ScriptDebugger`, `Documentation`, `About`, `CreateShaderSource`,
  `RefreshShader`, `AssignCube`.

**Do.**

1. Replace `_ => return` with an explicit arm per command, so the compiler
   lists what a new command must handle.
2. Implement:
   - `Copy`, `Paste`, and a new `Cut` (Ctrl+X): copy the selected objects
     with their children and components into an editor-owned buffer. Paste
     inserts them beside the selection with new ids, as one Undo step. Do
     not use the operating system clipboard for objects.
   - `SelectAll`: every object the Hierarchy currently lists.
   - `Projection`, `Front`, `Back`, `Left`, `Right`, `Top`, `Bottom`,
     `FreeView`: the viewport view presets, on the numpad keys Unity uses.
   - `Quit`: close the editor, asking about unsaved changes first.
   - `NewProject`, `OpenProject`: return to the project hub, asking about
     unsaved changes first.
   - `GameCamera`: Object, Camera creates an object with a Camera component.
   - `Documentation`: open `docs/guide/README.md` or the documentation URL
     with the platform opener in `rot-editor/src/platform/shell.rs`.
   - `About`: a dialog with the version, the licenses and the mark.
3. Delete: `CreateShaderSource`, `RefreshShader`, `AssignCube`, and whichever
   of `FocusRuntime` and `GameControls` duplicates the other. `GameUi`
   opens the existing Game HUD dialog or is deleted.
4. Leave to their own packages, with an explicit arm that names the
   package: the seven layout commands (`U-01`) and `ScriptDebugger`
   (`U-06`). If those packages are done, wire them here.
5. Give every remaining command a menu item with its shortcut shown.

**Done when.**

- No `_ =>` arm remains in `command()`.
- A test iterates `Action::ALL` and fails for a command that has no handler.
- In-process tests cover Copy then Paste (new ids, one Undo step, children
  kept), Cut, Select All and the unsaved-changes prompt on Quit.
- Screenshots of the Edit, Object and Help menus are viewed.

**Not now.** Copying components between objects (`U-04`). Copying objects
between two running editors.
