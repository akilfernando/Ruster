# U-03 · Menus, toolbar, Hierarchy rows and status bar to the standard

Lane UX · Size M · Depends on: U-01

**Outcome.** The window reads like Unity or Unreal at a glance: the standard
menus, an icon toolbar with Play in the middle, readable Hierarchy rows and a
status bar.

**Facts.** From screenshots of `c67b7d3` on 2026-11-27, against the
[window anatomy](../UX-STANDARDS.md#3-window-anatomy).

- Menus are File, Edit, Object, Assets, Window. There is no Component menu
  and no Help menu. The scene name is plain text beside Window.
- The toolbar shows the words "Select", "Move Tool", "Rotate Tool", "Scale
  Tool". Play, Step and Stop sit left of center. There is no layout picker.
- The AI indicator is not drawn. `scene_editor/ai_indicator.rs` only keeps
  state (`ai_status`).
- `scene_editor/toolbar_icons.rs` has painted icons for Move, Rotate, Scale,
  Duplicate and Delete. No `mod` line declares it, so it is not compiled.
- Hierarchy rows show the eye and lock buttons on every row and leave about
  70 px for the name, so most names are cut off after eight characters.
  Rows have no expand arrow and no type icon.
- The Inspector header is a "Name" label above a field, then "Enabled".
- There is no status bar unless an error is showing.
- At 1280×800 the Inspector is cut off by the Assets panel.

**Do.**

1. Menu bar: File, Edit, Assets, Object, Component, Window, Help, with the
   items listed in section S-03 of
   [the 2026-11-25 archive](../archive/BACKLOG-2026-11-25.md). Component
   holds the same list as the Inspector's Add Component. Show
   `project · scene*` at the right, with `*` when there are unsaved changes.
2. Toolbar, one row: tool icon buttons on the left with tooltips such as
   "Move (W)"; Play, Pause, Step, Stop centered; layout picker and the AI
   indicator on the right. Declare and reuse `toolbar_icons.rs`. Paint
   missing icons; check a glyph with `fontTools` before using a font
   character. Below 1,100 px the left group overflows into a `»` menu.
3. AI indicator: the mushroom mark, grey with no AI app connected, Rot red
   when connected, slow pulse while an AI edit is applying. Click opens AI
   Connection.
4. Hierarchy rows: expand arrow, type icon, name. Eye and lock appear on
   hover, and stay visible on a row that is hidden or locked. Indent 14 px
   a level. The name gets the remaining width.
5. Inspector header on one row: type icon, name field, enabled checkbox.
   The Inspector body scrolls and is never clipped.
6. Status bar, one line, always present: latest message on the left;
   background progress with Cancel, then warning and error counts on the
   right. Clicking a count opens the Console.

**Done when.**

- Screenshots at 1280×800, 1920×1080 and 960×1080, in one Rot and one Plain
  appearance, are viewed and pass items 1 to 8 of the
  [UI checklist](../UX-STANDARDS.md#10-ui-review-checklist).
- A Hierarchy 240 px wide shows "Clerestory Mullion 3" in full in
  `examples/rot-yard/gallery.scene.json`.
- `tabwalk` visits menu, toolbar, Hierarchy, viewport overlay, Inspector,
  Assets, status bar in that order.
- Every toolbar control has a tooltip with its shortcut.

**Not now.** New panels. Changing what the Inspector sections contain.
