# P4-10c · Save data

Lane Play · Size S · Depends on: P4-10a

**Outcome.** A script saves and loads progress and settings that are still
there the next time the game starts.

**Why.** Unity has PlayerPrefs and Unreal has SaveGame slots. Without either,
a game cannot remember a high score, an unlocked level or a key binding.

**Facts.** Checked 2026-11-27.

- There is no save API of any kind.
- `rot-support/src/platform/dirs.rs` has `home_dir`, `config_dir`,
  `state_dir_raw` and `runtime_dir`. It has no per-user data directory.
- Lua has no `io` or `os` library, by design. Saving must be a host
  function.
- The project name is in Project Settings and in the build's `app.json`.

**Do.**

1. Add `data_dir()` to `rot-support/src/platform/dirs.rs`: the per-user
   application data folder on each system (`$XDG_DATA_HOME` or
   `~/.local/share` on Linux, `%APPDATA%` on Windows, and
   `~/Library/Application Support` on macOS).
2. Save files live in `<data_dir>/<game name>/saves/<slot>.json`. The file
   is `{"format":"rot-save","version":1,"data":{...}}`.
3. Lua:
   - `host.save.set(key, value)`, `host.save.get(key, default)`,
     `host.save.delete(key)`, `host.save.clear()` use the slot named
     `default`.
   - `host.save.slot(name)` returns an object with the same four functions
     for another slot. `host.save.slots()` lists existing slot names.
   - Values are numbers, booleans, strings and nested tables of those.
   - Changes are written at the end of the tick that made them, and when
     the game quits.
4. Write to a temporary file in the same folder, then rename it over the
   old one. Keep the previous file as `<slot>.json.bak`. If a save file
   does not parse, load the `.bak` and log one warning. If neither parses,
   start empty and keep the damaged file under a new name.
5. Refuse a slot name that is not letters, digits, `-` or `_`. Refuse a
   save over 16 MiB with a script error.
6. In editor Play, saves go to `.rot-cache/play-saves/` inside the project
   so testing never touches a real save. Edit, Clear Play Save Data removes
   them.
7. Store runtime key bindings from `P4-08b` and bus volumes from `P4-07b`
   in the default slot under the reserved key `rot.settings`, and apply
   them at start.
8. Add to `docs/LUA-API.md` and a short section in the creator guide.

**Sample.** Best time per level, the highest unlocked level, music volume
and the Jump binding all survive a restart.

**Done when.**

- Tests with a temporary data directory: set then get across a new engine
  instance; nested tables round-trip; a truncated file falls back to the
  backup; both damaged starts empty; a bad slot name is refused; two slots
  stay separate.
- A player test saves, exits, starts again and reads the value.
- The Windows CI job passes.
- Nothing is written outside the two folders named above.

**Not now.** Saving the whole scene automatically. Cloud saves. Encryption.
