# R-05 · A creator guide that matches the editor

Lane Repair · Size M · Depends on: R-03

**Outcome.** A creator can read how to do each common job, and what they
read is true of the editor they have.

**Facts.** Checked 2026-11-27.

- `docs/CREATOR-WORKFLOW.md` is 1,260 lines. It was last changed before all
  of Phase 4 and says nothing about PBR materials files, sky, fog,
  post-processing, clustered lights, shadows settings, Rigid Body, Joint,
  Character Controller, skinned models or the animation state machine.
- The previous editor was removed on 2026-11-26 (`e106408`). Sections written
  before that date may describe dialogs that no longer exist. Treat each one
  as unverified.
- The editor has no Help menu and no link to any documentation.

**Do.**

1. Create `docs/guide/` with one short page per job. Each page is steps a
   person follows, in the editor's own words, with no history and no
   internals. Target 40 to 80 lines a page.
   - `getting-started.md`: install, create a project, the window, save.
   - `scene.md`: objects, Hierarchy, Inspector, gizmos, snapping, prefabs.
   - `assets.md`: the Assets folder, import, models, textures, materials.
   - `look.md`: lights, shadows, sky, fog, post-processing, view modes.
   - `scripting.md`: attach a script, properties, Play, errors, reload.
     Link to `docs/LUA-API.md` for the functions.
   - `physics.md`: Collider, Rigid Body, Joint, Character Controller, events.
   - `animation.md`: imported clips, skinned models, the state machine.
   - `play-and-build.md`: Play, Pause, Step, Play Values, Build, Build and Run.
   - `ai.md`: connect an AI app, what it can do, Undo, pausing AI edits.
2. Do each page's steps yourself in a disposable project with
   `scripts/ui_drive.py` or through MCP before you write them. Write only
   what worked. Put anything that did not work in the Inbox as one line.
3. Move the parts of `CREATOR-WORKFLOW.md` that are still true into those
   pages. Delete the file and fix links to it (`grep -rn CREATOR-WORKFLOW`).
4. Add a `README.md` in `docs/guide/` listing the pages in reading order.

**Done when.**

- Every page was followed start to finish on the current build. The commit
  message lists the pages and how each was checked.
- No page mentions a control that does not exist. Check with
  `python3 scripts/ui_drive.py ... labels:<name>` and compare the labels.
- The Markdown gate passes and nothing links to the deleted file.

**Not now.** A manual inside the editor. Translations. Screenshots in the
pages: add them after the UX lane settles the layout.
