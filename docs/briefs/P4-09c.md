# P4-09c · Game UI: buttons, focus and menus

Lane Play · Size M · Depends on: P4-09a, P4-08b

**Outcome.** A creator builds a menu from buttons. A player uses it with the
mouse, the keyboard or a gamepad.

**Why.** Unity's Button with its navigation, and Unreal's UMG focus, make
menus work on every input device without game code.

**Facts.** Checked 2026-11-27.

- `P4-09a` adds `UiCanvas`, `UiRect`, `UiText` and `UiImage`. Nothing in the
  new UI is clickable.
- The old HUD's Button calls a legacy script command. It stays as it is.
- egui already does hit-testing and keyboard focus inside the Game view.

**Do.**

1. `UiButton` on an object with a `UiRect`: `interactable` (default true),
   and four tint colors for normal, highlighted, pressed and disabled, with
   Unity's default values. The tint multiplies the color of the `UiImage`
   and `UiText` on the same object and on its children.
2. Clicking or activating a button calls `on_click(transform, props, host)`
   on the scripts of that object and emits a `ui_click` event carrying the
   object.
3. Focus: one button is focused at a time and draws a focus ring. Arrow
   keys, D-pad and left stick move focus to the nearest interactable button
   in that direction. Tab moves in Hierarchy order. Enter, Space and the
   South button activate. `host.ui.focus(obj)` sets focus. The first
   interactable button of a canvas that becomes enabled takes focus.
4. Moving the mouse over a button highlights it. Using the keyboard or pad
   again returns to the focused button. This is Unity's behavior.
5. UI keeps working while the game is paused or time scale is 0.
6. Input a button consumed does not also reach game actions that tick.
7. Lua handle: `interactable`, `set_interactable(b)`.
8. Editor: Object, UI, Button creates a button with an image and a text
   child. Inspector section with the four colors.
9. Add to the component catalog, the MCP schema and `docs/LUA-API.md`.

**Sample.** A title menu (Play, Options, Quit), a pause menu on Escape and
Start, and an options screen that rebinds Jump with
`host.capture_binding`.

**Done when.**

- Tests with synthetic input: click calls `on_click` once; focus moves
  right, left, up and down across a 2 by 2 grid; a disabled button is
  skipped; activating by gamepad works; a click does not also fire the game
  action bound to the same mouse button.
- A player test opens the pause menu and resumes.
- Screenshots of the title menu with the focus ring visible, viewed.

**Not now.** Sliders, toggles, dropdowns, text input, scroll views, layout
groups, animation of UI.
