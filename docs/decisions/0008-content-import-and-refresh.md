# 0008 Bounded mesh assets and controlled refresh

Date: 2026-11-04. Status: agent-selected implemented M6 architecture under the user's request to continue the next milestone. Implementation/acceptance tracked in STATUS.md. Extends0006; does not supersede logistics-v1 support or source licenses.

## Contract

Import one real owned-content route: bounded triangle-only Wavefront OBJ into validated position/flat-normal/index meshes. No textures, MTL, skeletal animation, arbitrary polygon triangulation or universal CAD/glTF support. Original source files remain user-owned; derived caches are disposable. A stable project catalog maps bounded asset IDs to confined project-relative source paths and the last successful SHA256 import recipe. Rename preserves ID; scene objects reference IDs rather than paths. Do not use raw IDs as filesystem cache names.

The catalog `.ruster-assets.json` is a separately revisioned authored file with full-baseline/advisory-lock cooperation. Import/Refresh/Rename persist catalog state immediately; scene assignment is a separate revisioned, undoable operation. Scene Undo/Discard does not rename/delete source files or undo catalog operations. An unused catalog entry after an interrupted assignment is safe. There is no atomic two-file project save claim. Alternatives: embedding catalog in scene would unify save/undo but couple asset discovery to one scene; per-source sidecars and a larger project database add unnecessary machinery. Revisit coordination if actual cross-scene workflows require it.

Refresh prepares bounded source/import/cache candidates before publishing accepted content/hash. Invalid/missing sources preserve last valid in-memory mesh and accepted cached result where available, with explicit diagnostic status. If both cache and usable source are absent, preserve the reference and show a missing-content placeholder; do not claim impossible recovery. Cache keys include importer recipe version and source hash; validated cache envelopes include mesh hash/version/bounds. Corrupt/deleted cache rebuilds from unchanged accepted valid sources. Changed sources require explicit Refresh rather than silently entering the scene. Source rename refuses overwrites and attempts rollback if catalog persistence fails; failures report actionable errors. No background watcher or arbitrary Rust hot reload.

Scene format2 adds optional mesh IDs and tagged shared transform/mesh history. Strictly decode scene-v1 objects/history; reject v2 fields under a v1 label. Preserve authored identity, revision and undo/redo. Saving explicitly upgrades to v2; UI/CLI docs state this. Logistics scenarios remain separately identified. The scene library validates references syntactically; project hosts resolve them and report missing content. Save As across roots with mesh references is rejected until dependency relocation/export is designed.

Renderer accepts immutable resolved mesh snapshots shared through Arc handles, with retained GPU buffers, actual imported bounds and triangle selection. Editor preview freezes both scene and resolved geometry until Reset; an asset refresh updates authored observation without replacing the captured preview. The shared scene shader is a separate trusted visual pipeline: explicit refresh of the project-local `scene.wgsl`, bounded64KiB, fixed entries/bindings/vertex contract. Candidate shader/pipeline validation must succeed before swapping; malformed/interface-invalid candidates retain the old pipeline. Shader refresh affects the viewport pipeline and is not runtime-state rollback or sandboxing against hostile local GPU code. Composite shader stays internal.

## Bounds, parity and measurements

Source<=1MiB, <=32768triangles, <=98304expandedvertices, <=64catalog entries, <=32MiB total resolved native payload and <=16MiB serialized cache per mesh. Project-relative paths and symlink confinement apply to all source operations. Registry baselines/revisions protect cooperating writers; source files can still be edited by ordinary noncooperating tools, so hashes identify the exact accepted read, not universal atomic capture of future edits.

Native MCP adds bounded catalog inspection, import/refresh/rename, mesh assignment and shader refresh. Require exact session/scene revision plus catalog or shader revision, pending-draft/dialog guards and actionable domain errors. Return IDs/hashes/status, never raw mesh/shader arrays. APIs/CLI/editor invoke the same source/scene operations. One-frame execution and byte/work caps remain; no automatic retries after unknown commit status.

Measure import/reimport/cache rebuild and edit-to-feedback on fixed declared source sizes; retain GPU synchronization/resize/shutdown and last-good shader evidence. Adding arbitrary meshes changes draw/buffer costs; previous three-cube performance is historical, not an equal-workload comparison. Tests cover v1 history migration, failed candidate atomicity, rename identity, cache reproduction, confinement, stale commands and native/client journeys before completion.
