# Rot Engine identity

Rot Engine is the product name. Use **Rot Engine** for the editor's
launcher, window title and About menu. Exported applications keep the
creator's title under the Rot Engine window-title prefix.

The November 2026 monogram-only branding pack supplies the mark and app
tile. The editor sets the product name in plain text. Use on-dark artwork on graphite
and on-light artwork on light surfaces. The artwork uses outlined paths.
The palette uses iron oxide `#BD5056`, deep oxide `#96373E`, graphite
`#10151B`, dark tile `#181F28` and frost `#E8EFF4`. Interactive
controls use contrast-adjusted oxide variants from the editor theme.
Warning, error and information colors represent their own states.
