# Rot Engine identity

Rot Engine is the product name. Use **Rot Engine** for the editor's
launcher, window title and About menu. Exported applications keep the
creator's title under the Rot Engine window-title prefix.

The active brand mark (confirmed by the user on 2026-11-25) is the **mushroom
mark** paired with the dark app tile:

- [Mushroom mark](../../../crates/rot-editor/assets/rot-mushroom.png) — used in
  the Project Hub, About dialog, and (converted to monochrome and tinted) as the
  toolbar AI connection indicator.
- [Dark app tile](../../../crates/rot-editor/assets/org.rot.editor.png) — used
  for the window icon and Linux desktop launcher.

The editor sets the product name in plain text. The Rot palette uses iron oxide
`#BD5056`, deep oxide `#96373E`, warm rose accent `#EF9AA2`, graphite `#151314`,
surface `#201D1E` and Rot red `#FA2934` for live state indicators (AI
connected, viewport selection outline, Play mode). See
[UX standards](../../UX-STANDARDS.md#9-rot-and-plain) for full Rot and Plain
palette tokens and motif guidelines.
