# Rusterize logo set

The selected Squared concept, redrawn as vector paths with custom inset lettering.

- marks/ contains the standalone R with embedded “ize” in dark-background, light-background, and single-color versions.
- lockups/ contains the Squared mark alongside the full Rusterize name. The wordmark is outlined DejaVu Sans Bold with tightened spacing.
- icons/ contains the Squared app tile with embedded “ize” in two themes, including a 128 px transparent-corner PNG and multi-resolution Windows ICO for each.
- Use the dark variants on dark backgrounds. Use the light variants on light backgrounds. The light mark uses deeper teal for contrast.

Palette
- Mint #72E6C0
- Frost white #E8EFF4
- Graphite #10151B
- Dark icon tile #181F28
- Light-theme deep teal #176554

SVG files contain outlines and require no installed fonts.
