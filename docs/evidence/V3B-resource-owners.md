For pinned Vulkan uploads, texture staging requested size is `Σ align_up(width×bpp,lcm(copy_pitch_alignment,bpp))×height`; current mesh initialization lengths already meet4byte alignment. The named NVIDIA reports copy-pitch alignment1, so image staging requested payload equals mip payload there. Other devices/backend rules differ. One admitted unresolved batch bounds initialization requests; allocator/driver peaks, ordinary frame uniforms and GUI resources remain separate. See `gpu-asset-staging-accounting-1/report.json` in the creation evidence.

Default equal-history settled PSS+2990KiB and sampled driver endpoints neither measure every peak nor prove queue ownership. The source review identified precisely that missing implication; it must be closed by executable adversarial completion/backpressure proof, not by another stable endpoint sample.
