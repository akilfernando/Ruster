## Implementation and source checks

Per-creation packaging performs no Cargo/build/notice regeneration, preserves exact Scene5/accepted OBJ bytes, validates its staged runtime at zero ticks and atomically publishes a fresh archive. Unrelated files are excluded. Runtime/profile bounds and receipt hashes are checked.

The shared editor controller captures scene incarnation/revision/save token/catalog/shader identities, runs bulk I/O off the UI thread, wakes on completion, and revalidates identity/directory authority before no-overwrite publication. One job and eight retained terminal receipts bound state; human replacement cancels but preserves inspection history/configuration. Human and MCP entry points share that operation. MCP adds inspect/start/cancel, explicit startup output grant and independently guarded template configuration;49tools total. `shader_refresh` optionally selects built-in appearance without modifying custom WGSL source.

## Root-changing Save As interleaving repair

A targeted source audit found a preexisting gap outside export: a human SaveAs to a new asset root could leave the same scene/session token and reset catalog/shader revisions to values an older agent had inspected. Export already had an independent persistence token, but content import/refresh did not. Extending the existing persistence case reproduced old `asset_import` succeeding against the new directory and advancing its catalog0→1.

Successful root-changing save now rotates the existing session incarnation after disk commit, cancels pending export, clears stale runtime-reset resource identity and immediately observes the runtime with the new incarnation. Existing external-editor saved coordination follows that new identity. Same-root/failed saves retain their session token; saved document/history, drafts and explicit grants retain their existing behavior. Successful command replies refresh the resulting session token instead of returning the admitted request's old token. Tests verify stale import/shader requests reject, new catalog stays0, saved bytes match and the root-changing MCP save reply matches subsequent inspection. No new wire field is needed.
