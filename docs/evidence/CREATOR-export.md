## Implementation and source checks

A once-prepared hashed runtime kit carries the executable/profile, selected dependency notices/ELF requirements and three fixed helpers. Per-creation packaging performs no Cargo/build/notice regeneration, preserves exact Scene5/accepted OBJ bytes, validates its staged runtime at zero ticks and atomically publishes a fresh archive. Unrelated files are excluded. Runtime/profile bounds and receipt hashes are checked.

The shared editor controller captures scene incarnation/revision/save token/catalog/shader identities, runs bulk I/O off the UI thread, wakes on completion, and revalidates identity/directory authority before no-overwrite publication. One job and eight retained terminal receipts bound state; human replacement cancels but preserves inspection history/configuration. Human and MCP entry points share that operation. MCP adds inspect/start/cancel, explicit startup output grant and independently guarded template configuration;49tools total. `shader_refresh` optionally selects built-in appearance without modifying custom WGSL source.

New Python boundary cases cover exact kit/content inventory, dependency-notice bounds, tampering, collisions, invalid runtime preflight and actual cancellation/reaping. Existing export-source test checks inclusion of the creation helper. Controller tests cover stale identities, cancellation/publication collisions/root replacement, bounded receipts and owned child cleanup. A real-egui frame test adds unique keyboard form/focus and guarded command wiring coverage; it is model evidence, not native desktop focus.
