## Costs and recommendation

Recommend narrow licensed core compatibility patch and a local egui adapter based on audited upstream adapter, preserving attribution/provenance. Alternatively vendor both packages with these6line changes. Separate view/projection camera access is necessary; existing renderer only exposes combined matrix internally. Host owns gesture transaction state: snapshot selected IDs/transforms at start, preserve selection/camera for a drag, preview independently, commit one guarded authored transaction on release, cancel/restore on Escape/focus loss/conflict. Upstream returns Some during interaction and None on release; it does not expose a public gesture-start/end/cancel object or perform authored undo. is_focused is hover/focus, not a stable public active flag. Avoid assuming all None results are successful commit boundaries.

Native visual alignment/occlusion/HiDPI/clipping, rotate/scale/local transforms, snapping, negative/degenerate scales, cancellation and focus-loss, text/camera shortcuts, state conflicts, persisted history and experienced-creator familiarity remain unverified. Adapter creates1pixel cursor interaction rectangle using previous-frame hit testing; moving pointer/overlaid UI needs acceptance in actual editor (steady hover only tested). Upstream core allocates returned Vec/draw data; no allocation or native binary/build-overhead measurements here. Representative editor full gate/notices/native journey remain root integration work. No user clipboard/focus/workspace change.
