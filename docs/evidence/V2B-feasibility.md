## Pure fit and first real GPU mechanism

`shadow_math.rs` is an isolated test-only module: f64 light-space bound accumulation, camera-independent square fit, robust basis, texel-aligned center, numerical/PCF padding and wgpu0..1 depth. It retains no assets and scans no mesh data. Three representative cases/tables protect containment for negative coordinates/nonuniform positive transforms, planes/points/thin/huge extents, finite near-axis directions, depth ordering, deterministic unordered bounds and invalid input. Negative transform scales remain rejected by the existing scene contract. CPU checks3/3 pass after3.63scompile,0.00stest execution. The worker formats only its file and runs no Cargo/GPU; initial PATH-only rustfmt fails, absolute-path invocation succeeds.

`shadow_probe.rs` is a separate opt-in ignored Vulkan mechanism check, not production authoring or shared-callback acceptance. It composes the existing builtin material/diffuse shader with a generic additive shadow interface, separate80byte projection/settings buffer, group3 sampled depth/comparison binding and depth-only pipeline that cannot sample its own attachment. Uses existing shared cube/instance buffers,512²single-sampledDepth32 and fixed3×3nearest comparisons. Explicit camera and geometry/light values establish known occlusion; no exhibit-specific shader or forged focus/render flag is used.

First compilation fails because MaterialGpu::prepare requires an Iterator rather than a one-element array; `.into_iter()` corrects it.
