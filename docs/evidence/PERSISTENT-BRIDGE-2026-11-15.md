## Transport and boundaries

- Python allocates a short private scratch directory (`0700`) and Unix listener path (`0600`) **before spawning** the native child. Native connects only to that explicit path. Python accepts once, verifies Linux `SO_PEERCRED` PID/UID against the exact child and current UID, and checks a random inherited handshake token plus exact native locator incarnation. Listener closes after binding; no reconnect, newest-editor discovery or old-file fallback. Native project's existing session/revision/view/draft guards remain the authoring authority. This is cooperative-user fixture protection, **not production human consent** or hostile-same-user isolation.
- Four-byte big-endian length + JSON. Requests are 1–4096 bytes; replies at most 8 MiB. Preserve the existing reply/base64 lossless PNG schema. Framing handles fragmented/coalesced stream delivery, partial writes and EOF. Absolute eight-second frame read/write deadlines do not reset on trickle progress; a healthy idle connection may wait for its first byte. Python uses one eight-second request/reply deadline and permanently closes a failed connection: ambiguous mutations are never replayed. Native independently bounds dispatch wait and reply write. No binary media protocol was needed.
- One IO worker owns blocking reads/writes, with one bounded request slot and one bounded reply slot. The editor uses only nonblocking channel operations; a partial header or stalled reader cannot block native editor processing. A complete request unparks the native thread, replacing unconditional post-frame sleep with wakeable `park_timeout(10ms)`. The maximum 10ms idle cadence and continuous fixture rendering remain; this is **not** an idle-efficiency rewrite or tight busy-spin.
- Existing browser one-flight admission, single camera-only coalesced intent, final delta settle, cancellation, decoded-frame advancement, Host/Origin/capability checks, project/incarnation/session guards, renderer/camera/selection/history and full native capture callbacks are retained. Browser HTML is unchanged. Status now requests cheap native pins through the same stream; it does not create a capture response. The explicitly granted first exact pending MCP owner is approved once by the fixture's native loop, removing server owner-file polling. It is still not production approval and cannot approve a replacement owner after revocation.
- Revocation immediately denies native operations/status through the existing live authority gate; the connection can deliver explicit refusal until owned shutdown. EOF, malformed framing or frame deadline retires the native fixture and its MCP locator; server shutdown closes the stream, joins native cleanup, and removes socket/capability. No transport-error recovery replays authored work.
