2026-11-05. Follow-up to the [native missing-viewport failure](m9-inspector-scale-blocker.png) from the [first inspector slice](M9-interaction-fix.md). **This bounded source/native pass is accepted; physical input and user visual approval remain open.** M9 as a whole is incomplete.

## Changed workflow

File/Edit/View menus expose the existing guarded commands and actual remapped shortcuts. Scene name, an unsaved marker and Save remain visible; long names truncate with their full value available. Once a committed runtime frame exists, the header explicitly identifies Authored or Runtime view, including stale state. Content/import and shader commands remain reachable with the browser hidden.

The runtime strip keeps labelled Reset, Play/Pause, Step and Stop. Its menu contains debugger opening, retained-frame viewing and technical diagnostics. Active stops, stale state and a bounded error summary/Open location remain visible. Runtime status stays in the shared status area even if a rejected operation retains a ready last-good frame; it is not classified by string matching or hidden behind ready/pending flags. Errors/recovery precede informational notices in a bounded scroll area. Actor, receipt, Save/Undo and runtime ownership semantics are unchanged.

Sidebars share a central-space budget, using their existing120/240-point minima and distributing remaining space according to preferred widths. Temporary constraints use separate stable panel IDs and exact effective widths without writing preferences; ordinary resizable panels return when space permits. Hidden panels consume no budget. Content height uses the area left after global bars, with scrolling allowed below its former64-point minimum. Narrow tool rows use existing menu controls for Space/Pivot/Snap, with active Local/Snap state visible. Fonts and control heights are preserved; no dependency, theme framework or general docking system was added.
