# M1 and M2 verification evidence

Date: 2026-11-04. M1 and M2 completed within the defined local scope; limitations below remain explicit.

## Environment

Linux CachyOS, Intel i9-13900H, Rust 1.99.1, Vulkan loader 1.4.363, Wayland desktop. Enumerated devices: NVIDIA RTX 4060 Laptop GPU (615.78.08), Intel Iris Xe (Mesa 26.2.5), llvmpipe. Enumeration is not a claim that all devices were tested.

The Khronos validation layer was missing. The distribution's vulkan-validation-layers 1.4.363 package was extracted under `~/.local/share/ruster-tools/vulkan-validation` without root/system changes. Runtime verification uses `VK_LAYER_PATH` for its manifest directory and `LD_LIBRARY_PATH` for its library directory. A user-local grim package supports viewport capture. These workstation tools are not application dependencies or bundled assets.

The Windows GNU Rust standard library target was installed for a bounded cross-platform compile assessment; no Windows host is available for runtime validation.

## Results

### M1

- 16 core/CLI tests passed, including corrupt/unsupported file input, history/revision boundaries, failed-save preservation and concurrent CLI writers (exactly one same-revision edit succeeds).
- [Recorded CLI journey](m1-demo.json): create, inspect, run, edit, stale rejection, undo, redo, copy/save, reopen/replay and reset. All expected exit statuses and counts matched.
- Process-level demo operations took 1.4–3.5 ms locally in debug builds, including process launch and file operations. This single warm demonstration is not a statistical performance claim. Initial dependency build/test was 5.91 seconds; subsequent focused test build 0.65 seconds.
- Source/API review found no blocking issue after correcting public-deserialization validation bypass and a revision-exhaustion/no-op edge.

### M2

Command (standard layer install):

```sh
cargo run -p ruster-viewer -- --scenario examples/logistics.scenario.json --validation --smoke 90
```

Workstation-specific validation environment:

```sh
export VK_LAYER_PATH="$HOME/.local/share/ruster-tools/vulkan-validation/usr/share/vulkan/explicit_layer.d"
export LD_LIBRARY_PATH="$HOME/.local/share/ruster-tools/vulkan-validation/usr/lib${LD_LIBRARY_PATH:+:$LD_LIBRARY_PATH}"
```

- Actual NVIDIA RTX 4060 Laptop GPU selected. [Smoke output](m2-smoke.txt) records 90 frames, reset after 20, final tick 70 / stock 70 / delivered 140 / produced 210, and exact headless replay equality.
- Synchronization validation explicitly enabled by the application with `--validation`; zero errors and zero warnings, including teardown.
- Smoke requested minimize/restore and resize; the tiling compositor did not honor the requested sizes. Separate interactive checks made the test window floating and verified actual 1100×720 → 640×480 → 1100×720 surface recreation. No persistent compositor configuration was changed.
- Keyboard event checks: N reached tick 1; play/pause advanced to tick 4 then paused; R restored tick 0. Right/Home camera actions were exercised. [Viewport capture](m2-viewer.png) was visually inspected for readable counts, labels and controls.
- [Interactive log](m2-interactive.txt): 9,713 frames, clean Escape shutdown, zero validation warnings/errors. Minimize/unminimize requests did not produce an independently confirmed minimized state under this compositor; this is a platform capability limitation, not evidence of tested minimizing on Windows.
- Unavailable-driver injection (`VK_DRIVER_FILES` pointing to a nonexistent manifest) returned exit 1 with “Unable to find a Vulkan driver”, without a hang.
- Smoke GPU command mean/p95: 0.0472/0.0480 ms (89 samples). CPU redraw including acquire mean/p95: 7.7357/11.8760 ms (90 samples). Frame intervals including lifecycle mean/p95: 10.5700/12.2404 ms. Debug build, validation on, FIFO, compositor-managed ~777×676 initial surface. These are diagnostic baselines, not release benchmarks or CPU/GPU performance superiority claims.
- First viewer build: 21.21 seconds with partially cached dependencies. Pure clipping and pre-desktop launch tests cover two distinct boundaries.
- `cargo check -p ruster-core -p ruster-cli --target x86_64-pc-windows-gnu --locked` passed (5.24s); viewer equivalent passed (7.52s). This is a compile assessment only, not a linked Windows package or runtime test.
- Unsafe review found a missing old-swapchain handoff during recreation; corrected before GPU runs. Partial-init cleanup, device-before-instance destruction and per-image presentation semaphore lifetime were reviewed.

### Final gate

`python3 scripts/check.py --full` passed: 13 runner tests, documentation checks, formatting, strict Clippy and 18 Rust tests. Wall time 3.24 seconds with warm caches. Afterward only documentation/evidence changed; documentation was checked separately rather than repeating unchanged Rust/GPU checks.

## Scope limitations

Vulkan 1.0 combined graphics/present queue and swapchain/color-attachment support form the current device baseline. Only this NVIDIA/Linux runtime is verified. Rendering uses 2D render-pass clear rectangles and bitmap glyphs, not shader-driven 3D meshes or materials. There is no editor/MCP integration yet. No production benchmark, power-loss durability, hostile filesystem defense or noncooperating-writer concurrency guarantee is claimed.
