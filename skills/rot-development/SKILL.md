# Rot Engine development

This skill is a pointer. The way of working is in the repository:

1. Read `AGENTS.md` at the repository root.
2. Read `docs/PLAYBOOK.md` and follow it.
3. Take the first open package in `docs/BACKLOG.md`.

When the user requests persistent goal tracking, use Astra's acceptance
criteria to set one active goal for the authorized scope. Track each Sol
implementation through coordinator review and integration. Keep the goal
active across completed slices and hosted checks, and honor the user's run
limit by finishing the work already in progress before stopping. If the
limit is a percentage of account usage, read the usage meter before
starting each slice.

Apply this only to the Rot Engine repository.
